Equity Connection pages: Webflow paste kit

Tomos wrote these two pages himself and asked for them as real landing pages we can use. The copy is his, unchanged. This kit puts each page into Webflow the same way the HVAC, electrical and fleet pages went in: four paste blocks per page, one block per Code Embed, and a native Webflow form so sign-ups save under Forms.

Four pastes per page. If a step gets missed, the page tells you on webflow.io. Each block is under Webflow's 50,000 character limit for a Code Embed. Tested in a stand-in Webflow page with deliberately clashing site styles: every element matched the original page on desktop and phone, and the form saved every field.

Sponsor page

Suggested slug/lp/equity-connection-sponsors
SEO titleEquity Connection for Independent Sponsors and Search Funds | SourceCo
DescriptionSourceCo Equity Connection: equity for independent sponsors and search funds through private equity firms, family offices and ultra-high-net-worth investors. Launching early 2027.
Open Graph imageimg/og-sponsors.jpg
Form nameEC Sponsors - Founding List

Steps

  1. Create a new blank page with no site nav or footer. Suggested slug: /lp/equity-connection-sponsors. Set the SEO title, description and Open Graph image from the table above.
  2. Add a Div Block and give it the ID ec-page in the Settings panel. Everything else goes inside it.
  3. Add a Code Embed inside the div and paste block 01.
    01 Styles28,997 characters
  4. Add a second Code Embed under it and paste block 02.
    02 Page content22,172 characters
  5. Add a Form Block under that. Leave its default fields alone, the script clears them. Add a Code Embed inside the form and paste block 03. Optional: name the form EC Sponsors - Founding List so submissions are easy to find.
    03 Form fields3,011 characters
  6. Add one last Code Embed under the Form Block and paste block 04.
    04 Page script25,159 characters
  7. Publish to webflow.io only. A small note in the bottom left corner says Setup check passed, or tells you what is off. Then fill in the form once and check the submission under Forms.

Before you publish

  • Three "Cheque size [$X to $X]" rows under "Who sees your deal" are left out until there are real ranges.
  • The "[Founding terms to confirm]" note and the "[Founding sponsor terms to confirm]" note in the FAQ are left out.
  • "If one closes with another buyer, you share in the fee." is still highlighted in gold. Confirm it or cut it before publishing.
  • The footer lists coinvest@sourcecodeals.com. Check that inbox exists, or tell Ricky which address to use.
  • Footer links point to /lp/equity-connection-sponsors and /lp/equity-connection-investors. If you use different slugs, tell Ricky and he will update the blocks.
  • Images load from Ricky's preview site for now, so the page works as soon as you paste. When you have a minute, upload the files in the zip's img folder to Assets and swap the URLs.
  • Decide whether the page should be indexed. The seller landing pages are a good guide.

What each sign-up saves

stage, sponsor_type, deals_closed, target_ebitda, sectors, wants, equity, first_name, last_name, firm, email, mobile, industries_focus, deal_details, heard_from, plus the usual UTM and click ID fields, lead_id, page_variant, lp_name and page_url.

Editing copy

  • Or send Ricky the change and he will send back the updated block.

Tracking

The page pushes three events to dataLayer: coinvest_lead when someone finishes the form, ec_lead_saved when Webflow confirms the save, and ec_lead_error if the save fails. If a save fails the visitor sees a Try again link.
